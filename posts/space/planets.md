We have sent robots to our Moon, Mars, Venus, and even an asteroid. And now we are planning to send one to Titan (a moon in Saturn) in a few years. But there is still a lot to explore out there, so let's think the following fun idea:

> Say we have an "invincible rover", meaning a robot that can explore a planet or moon while withstanding any pressure, radiation, heat (or lack of), and environment. Where should we drop it?

First, let's consider the candidates:

(Source)[https://science.nasa.gov/solar-system/]. Our solar system has one star (the Sun), 8 planets and 5 dwarf planets. From closest to furthest from the Sun, we have:
- Mercury
- Venus
- Earth
- Mars
- Jupiter
- Saturn
- Uranus
- Neptune

And for dwarf planets, we have:
- Ceres
- Pluto
- Haumea
- Makemake
- Eris

Regarding the moons and asteroids, perhaps there are too many to list them here. Consider the bigger and perhaps most relevant ones:

| Planet | Moons |
|--------|-------|
| Mercury | None |
| Venus | None |
| Earth | Moon (the one we all know) |
| Mars | Phobos, Deimos |
| Jupiter | 95, mainly Ganymede, Callisto, Io, Europa |
| Saturn | 274, mainly Titan, Enceladus, Hyperion, Mimas, Dione, Iapetus |
| Uranus | 28, mainly Miranda, Ariel, Umbriel, Titania, Oberon |
| Neptune | 16, mainly Triton, Despina |
| Ceres | None |
| Pluto | 5: Charon, Nix, Hydra, Kerberos, Styx |
| Haumea | Namaka, Hi'iaka |
| Makemake | "MK 2" |
| Eris | Dysnomia |
